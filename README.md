# Структурований бриф на розробку інтернет-магазину риболовлі з адмін-панеллю

Повноцінне веб-рішення для збору та адміністрування брифів клієнтів з реалізацією бекенду на **чистому PHP (архітектурний патерн MVC)** та сучасного фронтенду на **React 18 + TypeScript + Vite**, який компілюється та зберігає готову продакшн-структуру у папці `view/`.

---

## 🌟 Основні можливості

1. **Публічний бриф на одній сторінці (Single-Page Form)**:
   - Всі 6 розділів та 34 запитання розміщені на одній сторінці без розбивки на пагінаційні кроки (згідно зі структурою форми).
   - Плаваюча бокова панель навігації (`SectionNav`) для швидкого скролу між розділами з індикаторами прогресу.
   - Автоматичне збереження відповідей у `localStorage` у реальному часі.
   - Валідація обов'язкових полів та коректності номерів телефонів.
   - Генерація унікального номера брифу (наприклад, `BRF-20260826-XXXXX`).
   - Модальне вікно успішного заповнення з можливістю завантажити копію у JSON або роздрукувати / зберегти у PDF.

2. **Захищена адмін-панель (`/admin` або `#admin`)**:
   - Окремий захищений вхід для менеджерів та адміністраторів (JWT / Session token).
   - Аналітичний дашборд: статистика за статусами (нові, в обробці, погоджені, завершені, відхилені) та бюджетами.
   - Фільтрація, пошук за ім'ям клієнта, телефоном, назвою магазину чи номером брифу.
   - **Повноцінний редактор збережених відповідей**: можливість редагувати будь-яку відповідь клієнта, змінювати контакти, статус, додавати внутрішні нотатки менеджера.
   - Потоковий експорт усіх збережених брифів у **CSV (Excel з підтримкою кирилиці)** та **JSON**.

3. **Оптимізація ресурсів пам'яті та буферизація**:
   - Патерн **MVC** (Core, Controllers, Models, Views).
   - Буферизація сторінок (`ob_start` + gzip compression).
   - Потокова генерація великих наборів даних (PHP Generators / Cursors) без переповнення `memory_limit`.
   - ETag та `304 Not Modified` кешування статичних ресурсів.

## 🚀 Інструкція з локального запуску та тестування

### Крок 1. Запуск бекенду на PHP
Ви можете запустити бекенд або через вбудований сервер PHP, або через WAMP Server:

**Варіант А: Через вбудований сервер PHP (рекомендовано для швидкого тесту):**
```bash
# У корені проекту (d:\brief)
php -S 127.0.0.1:8000 index.php
```

**Варіант Б: Через WAMP Server:**
1. Скопіюйте папку проекту `brief` у директорію `C:\wamp64\www\brief`.
2. Відкрийте phpMyAdmin (`http://localhost/phpmyadmin`) та імпортуйте `database/schema.sql`.
3. Бекенд буде доступний за адресою `http://localhost/brief/`.

---

### Крок 2. Встановлення залежностей та запуск фронтенду (`npm i`)

> [!IMPORTANT]
> Директорію `node_modules/` додано до `.gitignore` задля чистоти репозиторію, тому після першого клонування репозиторію обов'язково потрібно ініціалізувати та встановити всі NPM-пакети командою `npm i` (або `npm install`).

```bash
# Перейдіть у папку фронтенду
cd frontend

# 1. Ініціалізація та встановлення бібліотек (створює локальну папку node_modules)
npm i

# 2. Запуск сервера розробки з Hot Module Replacement (HMR)
npm run dev
```

Після запуску відкрийте браузер за дефолтною адресою: **`http://localhost:5173`**  
Усі API-запити до `/api/*` автоматично проксуються через Vite на працюючий PHP-бекенд.

---

### Крок 3. Компіляція фронтенду у папку `view/`
Коли ви вносите зміни у фронтенд-код і хочете зібрати продакшн-версію:
```bash
cd frontend
npm run build
```
Vite автоматично скомпілює додаток і збереже оптимізовані файли безпосередньо у директорію `view/` (`view/index.html`, `view/assets/index.css`, `view/assets/index.js`).

Після цього додаток одразу працює через PHP сервер без необхідності запущеного Node.js:
`http://127.0.0.1:8000` або `http://localhost/brief/`.

## 🌐 Інструкція з розгортання на безкоштовному хостингу Byethost

1. **Реєстрація та доступ**:
   - Увійдіть у панель керування cPanel вашого акаунту Byethost (наприклад, `cpanel.byethostXX.com`).

2. **Створення бази даних MySQL**:
   - У cPanel відкрийте розділ **MySQL Databases**.
   - Створіть нову базу даних (наприклад, `b12_12345678_brief`).
   - Створіть користувача MySQL та надайте йому повні права на створену базу даних.
   - Відкрийте **phpMyAdmin** у cPanel Byethost і виконайте імпорт файлу `database/schema.sql`.

3. **Налаштування підключення до БД**:
   - Відкрийте файл `config/database.php` та вкажіть параметри хостингу Byethost:
   ```php
   'mysql' => [
       'host' => 'sqlXXX.byethostXX.com', // Хост MySQL з панелі Byethost
       'port' => '3306',
       'dbname' => 'b12_12345678_brief',   // Ваше ім'я БД
       'username' => 'b12_12345678',       // Ваш логін БД
       'password' => 'ваш_пароль_БД',
       'charset' => 'utf8mb4',
       ...
   ]
   ```

4. **Завантаження файлів на хостинг**:
   - За допомогою FileZilla (FTP) або вбудованого File Manager завантажте весь вміст проекту `d:\brief\` у кореневу папку хостингу: `/htdocs/` (або `public_html/`).
   - Переконайтеся, що файл `.htaccess` завантажено до кореня `htdocs/`.
   - Файли скомпільованого фронтенду повинні знаходитися у папці `htdocs/view/`.

5. **Готово**:
   - Відкрийте ваш сайт `http://ваш-домен.byethostXX.com/` — відкриється публічний бриф.
   - Відкрийте `http://ваш-домен.byethostXX.com/#admin` — відкриється адмін-панель для перегляду та редагування відповідей.
